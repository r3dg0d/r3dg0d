# Hi, I'm r3dg0d

I love **super-intelligence (SI)** and building **free and open-source software (FOSS)** — tools other people can use, study, and improve.

I run **NixOS**, and my favourite language is **C++**: it's old and proven, yet still powers so much of the software we rely on every day — browsers, game engines, operating-system components, and more.

I have experience in the **PS5 homebrew scene** and in **game modding**, alongside building games and player tools.

I'm a believer in **privacy** — support the work of the [EFF (eff.org)](https://www.eff.org).

## Featured projects

- [**stream-able**](https://github.com/r3dg0d/stream-able) — OBS-like recording, livestreaming, and multistreaming studio inside Minecraft (Fabric mod).
- [**blurcam**](https://github.com/r3dg0d/blurcam) — Native C++ face privacy for Linux: local blur, pixelation, and virtual-camera output, no cloud.
- [**MatrixShot**](https://github.com/r3dg0d/MatrixShot) — Wayland-native screenshot and screen-recording suite with a Matrix-themed overlay.
- [**nixpresence**](https://github.com/r3dg0d/nixpresence) — VRChat OSC chatbox compositor with optional Discord Rich Presence.
- [**dotfiles**](https://github.com/r3dg0d/dotfiles) — My deep-space niri rice for NixOS.

Everything else is on my [repositories page](https://github.com/r3dg0d?tab=repositories).
